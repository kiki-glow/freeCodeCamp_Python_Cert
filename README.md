This repository contains my solutions for the **freeCodeCamp Python Certification**.
Each folder represents a project or lab completed as part of the curriculum and
passes all required freeCodeCamp tests.

The goal of this repository is to document my learning progress and demonstrate
core Python concepts through practical, test-driven exercises.

---

## Projects

| Project | Description |
|-------|-------------|
| Number Pattern Generator | Generates a space-separated number pattern from 1 to _n_ |
| PIN Extractor | Extracts a numeric PIN from a poem using word-length logic |
| Caesar Cipher | Encrypts and decrypts text using a Caesar shift |
| Character Creator | Validates and formats RPG-style character stats |
| Budget App | Tracks budget categories and spending |
| Email Simulator | Simulates sending and managing email |
| Game Character Stats Tracker | Tracks game character statistics |
| Medical Data Validator | Validates medical data |
| Musical Instrument Inventory | Manages an inventory of musical instruments |
| Planet Class | Models planets with an object-oriented class |
| Salary Tracker | Tracks salary information |
| User Config Manager | Manages user configuration settings |
| Algorithm exercises | Binary search, bisection, sorting, Luhn validation, and Tower of Hanoi (`algorithms/`) |
| Data structure exercises | Linked list and hash table implementations (`Data_Structures/`) |
| Dynamic programming | Fibonacci number calculation (`Dynamic_Programming/`) |
| Graph and tree exercises | Graph traversal, shortest path, adjacency conversion, parentheses generation, and N-Queens (`Graphs/`) |
| Object-oriented programming exercises | Discount calculator, inheritance, media catalogue, player interface, and polygon area calculator (`OOP/`) |
